Round 1 — 9/10

Question 1: Malware automatically spreads between computers by exploiting a network service vulnerability, without users opening files or running programs. What is it?
  • A. Trojan
  • B. Worm
  • C. Logic bomb
  • D. File-infecting virus

My answer: B. Correct answer: B — Worm.

Question 2: A downloaded PDF converter secretly gives an attacker remote access when installed. What is it?
  • A. Worm
  • B. Trojan
  • C. Logic bomb
  • D. Spyware

My answer: B. Correct answer: B — Trojan.

Question 3: Malicious code deletes company files if a particular employee's account is disabled. What is it?
  • A. Ransomware
  • B. Rootkit
  • C. Logic bomb
  • D. Worm

My answer: B. Correct answer: C — Logic bomb.

Question 4: Malware sends users' keystrokes to an attacker, capturing typed passwords. What most specifically describes it?
  • A. Keylogger
  • B. Ransomware
  • C. Worm
  • D. Rootkit

My answer: A. Correct answer: A — Keylogger.

Question 5: Employees cannot open their files and receive a demand for payment in exchange for a decryption key. What is it?
  • A. Spyware
  • B. Logic bomb
  • C. Ransomware
  • D. Trojan

My answer: C. Correct answer: C — Ransomware.

Question 6: Malware conceals malicious files and processes while maintaining administrator-level access. What is it?
  • A. Rootkit
  • B. Worm
  • C. Ransomware
  • D. Keylogger

My answer: A. Correct answer: A — Rootkit.

Question 7: A malicious program attaches to an executable and infects other executable files when the user runs it. What is it?
  • A. Worm
  • B. Virus
  • C. Trojan
  • D. Logic bomb

My answer: B. Correct answer: B — Virus.

Question 8: Software secretly collects browsing history, takes screenshots, and transmits information to a third party. What is it?
  • A. Ransomware
  • B. Worm
  • C. Spyware
  • D. Logic bomb

My answer: C. Correct answer: C — Spyware.

Question 9: A slow workstation has high CPU usage and an unauthorized cryptocurrency mining process. What is this activity?
  • A. Cryptojacking
  • B. Keylogging
  • C. Ransomware
  • D. Logic bomb

My answer: A. Correct answer: A — Cryptojacking.

Question 10: Malicious code remains inactive until a specific date, then deletes backup files. What is it?
  • A. Rootkit
  • B. Trojan
  • C. Logic bomb
  • D. Worm

My answer: C. Correct answer: C — Logic bomb.

Round 2 — 9/10

Question 1: An employee enables macros in a spreadsheet; malicious code runs and infects other spreadsheets. What is it?
  • A. Worm
  • B. Macro virus
  • C. Rootkit
  • D. Logic bomb

My answer: B. Correct answer: B — Macro virus.

Question 2: Malware modifies operating system components to hide files and processes from security tools, persisting after suspicious applications are removed. What is it?
  • A. Spyware
  • B. Ransomware
  • C. Rootkit
  • D. Macro virus

My answer: C. Correct answer: C — Rootkit.

Question 3: A free browser extension secretly records browsing activity and sends screenshots externally. What best describes its primary function?
  • A. Trojan
  • B. Spyware
  • C. Worm
  • D. Ransomware

My answer: B. Correct answer: B — Spyware.

Question 4: Malware spreads between servers without user interaction. What best limits spread during cleanup?
  • A. Change employee passwords
  • B. Isolate infected servers from the network
  • C. Disable spreadsheet macros
  • D. Increase backup frequency

My answer: B. Correct answer: B — Isolate infected servers.

Question 5: A script checks payroll daily and deletes critical files if its creator's name disappears. What is the key logic bomb clue?
  • A. Runs daily
  • B. Accesses sensitive information
  • C. Destruction depends on a specific condition
  • D. Creator is an employee

My answer: C. Correct answer: C — Conditional trigger.

Question 6: A fake software update encrypts files and demands payment. What describes delivery and function?
  • A. Trojan delivering ransomware
  • B. Worm delivering spyware
  • C. Rootkit delivering a macro virus
  • D. Logic bomb delivering a keylogger

My answer: A. Correct answer: A — Trojan delivering ransomware.

Question 7: A tool flags a new program for rapidly modifying files and disabling recovery, without a known malware signature. Which detection method is used?
  • A. Signature-based detection
  • B. Behavior-based detection
  • C. File hash matching
  • D. Manual code review

My answer: B. Correct answer: B — Behavior-based detection.

Question 8: An employee autofills a password instead of typing it. Which malware capability is most directly bypassed?
  • A. Recording individual keystrokes
  • B. Capturing screenshots
  • C. Stealing session cookies
  • D. Reading credentials from browser memory

My answer: D. Correct answer: A — Recording individual keystrokes.

Question 9: After files are restored from ransomware, the attacker threatens to publish documents stolen before encryption. What does this demonstrate?
  • A. False positive
  • B. Double extortion
  • C. Logic bomb
  • D. Resource exhaustion

My answer: B. Correct answer: B — Double extortion.

Question 10: An attachment executes malware that then independently exploits network services to copy itself between computers. Which characteristic identifies the worm component?
  • A. Arrived through email
  • B. Conceals itself in a legitimate file
  • C. Spreads without further user action
  • D. Executes only on a specific date

My answer: C. Correct answer: C — Autonomous spread.

Review takeaways

  • Logic bomb vs. rootkit: A logic bomb triggers on a condition. A rootkit hides malicious activity and supports privileged access. I missed this distinction in Round 1, then answered later logic bomb scenarios correctly.
  • Autofill: Avoiding typed keystrokes bypasses basic keystroke-only capture. It does not stop malware from reading browser memory or capturing form values through other methods. This was my Round 2 correction.
