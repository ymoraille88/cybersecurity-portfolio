Recent Practice Questions

{{ review.label }}: {{ review.correct }}/{{ review.questions }} correct ({{ review.percent }}%). The examples below come from my shared study notes.

Stolen password, blocked sign-in

An attacker has a user's password, but remote access is denied because an additional verification method is required. Which control prevented access?

Answer and explanation

Multifactor authentication. It requires another factor beyond the stolen password.

A targeted gift-card request

An attacker researches a CEO and emails a specific employee, impersonating the CEO and requesting gift cards. What type of attack is this?

Answer and explanation

Spear phishing. This is a targeted phishing attack aimed at a specific person or organization.

Many passwords, one account

Hundreds of login attempts use different common passwords against the same username. Which attack does this describe?

Answer and explanation

Brute-force attack. Many passwords are tried against one account. Password spraying instead tries one or a few common passwords across many accounts.
